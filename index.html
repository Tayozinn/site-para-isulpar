👨‍💻 Área do Aluno: Como integrar seu projeto ao Portal

Baixar Código-Fonte no GitHub

Os cartões marcados como Espaço Reservado já estão estruturados no código aguardando o link de cada equipe. Pode clonar o nosso repositório para usar o layout padrão ou hospedar o seu site próprio e enviar-nos os dados abaixo para atualizarmos o arquivo src/models/ProjetoModel.js: 

{
  id: 1, // Número da sua disciplina (1 a 11)
  nome: "Nome da Disciplina",
  equipe: "Nome dos Integrantes",
  status: "publicado",
  url: "https://link-do-projeto-do-grupo.github.io/"
}
